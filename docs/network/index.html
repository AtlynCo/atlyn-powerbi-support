Atlyn Network 1.2.0.0

Quick start, field mapping, layouts, formatting, limits, and support for the Atlyn Network Power BI visual.

Atlyn Network renders directed relationships in Power BI. This guide covers the field wells and local exploration options. For other support questions, visit the FAQ.

Quick start

  1. Add the Atlyn Network visual to a report page and map Source ID and Target ID to identifiers for the relationship endpoints.
  2. Optionally map Weight, Relationship type, Edge ID, Item ID, and Tooltips to add relationship values, stable identity, item detail, and tooltip context.
  3. Choose a layout, then use search, traversal, formatting, and report selection to explore the graph.

Field wells

  • Source ID: Identifier for the source entity in a directed relationship.
  • Target ID: Identifier for the target entity. Blank targets can be grouped with the related formatting option.
  • Weight: Optional relationship magnitude.
  • Relationship type: Optional relationship category or label.
  • Edge ID: Optional relationship identifier.
  • Item ID: Optional item identifier for the Two-Ring Item Detail drill-in.
  • Tooltips: Optional values for additional tooltip context.

Layout modes

  • Force-directed: Explore a directed graph, including cycles, reciprocal links, and self-links.
  • Circular ring: Use a single-ring overview. Map Item ID to enable the Two-Ring Item Detail drill-in.
  • Rooted radial: Explore directed relationships in a rooted radial arrangement.

Formatting options

  • Color mode: Use categorical source coloring for relationship curves and arrowheads.
  • Role rings: Show concentric rings for source and target roles.
  • Self-links: Hide diagram self-links while retaining their status counts.
  • Group blank targets: Optionally place relationships with blank targets in a bucket.

Local exploration and report selection

Search, neighborhood, upstream, downstream, shortest-path traversal, and saved local views change the visual view. Selecting an entity or relationship uses native Power BI selection and cross-filtering to interact with connected report visuals.

Scale limits

Keep the visual within 5,000 rows, 250 entities, and 1,000 relationships.

Data and privacy
